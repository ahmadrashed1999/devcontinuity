# Code of conduct

DevContinuity is built by people who use many AI coding agents and want them to work together. We
want the project to be welcoming to everyone who shares that goal, whatever their experience,
language, background or identity.

## What we expect

- Be kind and patient. Assume good intent, especially with newcomers and with people writing in a
  second language (English and Arabic are both welcome here).
- Critique code and ideas, not people. Explain the "why", and accept that others may decide
  differently.
- Respect privacy. Never post someone's transcripts, tokens, paths or personal details, and ask
  before sharing anything from a private conversation.
- Credit others' work and say so when you used an AI agent to help write a contribution.

## What is not acceptable

- Harassment, insults, personal or political attacks, and discriminatory jokes or language.
- Sexualized language or imagery, and unwelcome attention of any kind.
- Publishing others' private information, or threatening to.
- Repeatedly pushing a point after a maintainer has asked you to stop.

## Enforcement

Maintainers may edit or remove comments, commits, issues and other contributions that break this
code, and may temporarily or permanently ban anyone from the project's spaces.

To report a problem, contact the maintainer privately through
[a private GitHub security advisory](https://github.com/ahmadrashed1999/devcontinuity/security/advisories/new)
(choose it even for conduct reports; it is the private channel GitHub offers) or a direct message to
the maintainer's GitHub account. Reports are handled confidentially, and reporters will not be
retaliated against.

This code applies in every project space (issues, pull requests, discussions) and when someone
represents the project elsewhere.

It is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
